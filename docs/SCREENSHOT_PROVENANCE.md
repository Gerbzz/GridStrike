# GridStrike screenshot provenance

These images are direct PNG captures of a live, retained Windows GridStrike window. They are not mockups or composites. GridStrike's own localhost control API handled `ui.screenshot`; the app was launched with `GRIDCRAFT_NO_PREFS=1` so the session did not read or write user preferences. Both workbooks are original samples generated by the included `crates/engine/src/sample.rs` source.

The executable was the retained `gridstrike.exe` with SHA-256 `ED34C36E17A8C065647D718ABCEB00E01E1245BBA0C8A7C794968697D8471A9E`. Its depfile points to the reviewed GridStrike source candidate. All 278 public source, manifest, and app-icon blobs in the comparison set matched that candidate byte for byte. The depfile also names two `contributors/` inputs absent from the retained candidate and public tree; these do not affect the visible workbook sample, but the provenance claim is limited to the matched files.

In the live run, the sales sample saved to a local XLSX file (11,150 bytes; SHA-256 `CF5053D2098001AE7653A0C6578B007A91C4551B2709FDC93977B59263689183`). The app reopened it and returned cell `G5` with formula `=SUM(C5:F5)` and calculated value `217420`. The screenshot of the budget was taken after opening a separate original sample. The local XLSX and diagnostic control scripts are evidence only and are not distributed with this repository.

This bounded capture verifies those particular Windows UI states and the save/reopen formula round trip. It does not establish broad format compatibility or release readiness.
